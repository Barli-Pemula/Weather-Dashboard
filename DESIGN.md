# Weather Studio design
Software: a working weather dashboard for Jakarta, not a marketing landing page.
Direction: a warm, editorial weather instrument. Off-white canvas, forest green current conditions, sage outlook and restrained ochre for temperature highs.
Typography: Manrope, retained from the project for readable small labels and large tabular weather values.
Composition: equal content edges, a prominent current-weather panel, a compact weekly list, four current metrics and a temperature chart. Layout follows data density rather than full-screen marketing sections.
Desktop: centered 1200px content, two columns, inline navigation. Tablet: narrower paired columns. Mobile: one column, current metrics before the weekly list, labeled bottom navigation with safe-area spacing.
Interaction: visible current page and keyboard focus, real forecast links, restrained hover feedback; no looping decoration. Respect reduced motion.
Data: Open-Meteo; no fabricated air-quality, visibility or tomorrow values. Daily cloud maximum is derived from hourly cloud cover. Display units and Jakarta local timestamps.
No generated photographs, logos, testimonials, new brand names, shader scenes or marketing animation sections are needed for this data tool.
